# EyeLabX

### Digital Eye Wellness & Technology Website

**Live Website:** [https://eyelabx.com/](https://eyelabx.com/)

## Overview

EyeLabX is a digital eye wellness and technology platform focused on eye protection, attention wellness and technology designed to support healthier digital experiences.

I developed the website as a modern, responsive web experience with a focus on performance, clean interface design, smooth animations and clear presentation of the company's products, technology and solutions.

## My Role

**Frontend Web Developer**

I was responsible for the frontend development, interface implementation, responsive layouts, animations and deployment of the website.

## Tech Stack

- React
- Next.js
- Tailwind CSS
- Framer Motion
- Vercel
- Cloudflare

## Development & Infrastructure

### Frontend

- Built the website using React and Next.js
- Implemented responsive layouts for desktop, tablet and mobile
- Created reusable UI components and page sections
- Styled interfaces using Tailwind CSS
- Implemented smooth animations and transitions with Framer Motion
- Focused on clean, modern and accessible user interfaces

### Performance & Deployment

- Configured the website for production deployment on Vercel
- Utilized Next.js capabilities for server-side rendering and static page generation
- Optimized the frontend for fast loading and responsive performance
- Configured Cloudflare for DNS management, SSL and CDN distribution
- Utilized Cloudflare security features for additional protection
